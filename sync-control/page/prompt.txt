Sync Control page for the AlSanidi | Marketing app (Integration area, Sync Control group). One card per ad platform from the Integration Platform table (Meta, Snap, Google Ads, TikTok shown as "Not set up yet"). Each card has a Data part and an Insights part showing the latest run date and status from the flow run history (Data lists every flow in its chain with its latest status; a failure shows the failed flow and its error message). System Administrators see Sync Data and Sync Insights buttons; each asks for confirmation, then creates an Integration Sync Request row that the dispatcher flow picks up; the part shows Running with the new date straight away and the result appears on Refresh. Other users see the page read-only. The page refreshes only when Refresh is pressed.
